Overview Workflow Functions Operations Example Limitations

Overview

assignment1.py reads student records from a CSV file. It calculates the average grade for all records, selects students whose grades are at least 80.0, and prints a report containing those students.

Input

A path entered by the user and a CSV file with Name and Grade columns.

Processing

Rows are stored as dictionaries, grades are converted to floating-point numbers, and records are filtered.

Output

The overall average grade and a report of qualifying students are printed in the terminal.

Program Workflow

Ask for the file path

input() displays a prompt and stores the user's response in file_path.

Open and read the CSV file

open() opens the file. csv.DictReader turns each row into a dictionary whose keys come from the header row.

Build the records list

Each dictionary is added to records with append().

Find qualifying students

starstudents(records) returns records with grades greater than or equal to 80.0.

Calculate the average

avg_grade(records) converts each grade to a number, adds the grades, and divides by the number of records.

Print the results

avg_grade_print() prints the average. student_report_print() prints each qualifying student's name and grade.

records = read CSV rows
filtered_records = starstudents(records)
average = avg_grade(records)
avg_grade_print(average)
student_report_print(filtered_records)

Function Reference

avg_grade

avg_grade(inpt)

Calculates the average grade of the supplied student records.

ItemDescription
Parameterinpt: an iterable of dictionaries containing a Grade value.
Return valueA number representing the average grade.
How it worksA generator expression converts each Grade value with float(). sum() adds the converted values, and the result is divided by len(records).
Side effectsNone, but it depends on the global records list for the divisor.

avg_grade_print

avg_grade_print(inpt)

Displays the calculated average grade in a formatted message.

ItemDescription
Parameterinpt: normally the value returned by avg_grade().
Return valueNone. The function prints text instead of returning a value.
How it worksAn f-string inserts the value into Average Grade: ..., then a separator line is printed.
Side effectsWrites two lines to standard output.

starstudents

starstudents(inpt)

Creates a list containing students whose grade meets the threshold.

ItemDescription
Parameterinpt: an iterable of dictionaries containing a Grade value.
Return valueA new list of records where float(item['Grade']) >= 80.0.
How it worksA list comprehension examines each item, converts its grade to a number, and keeps the item when the condition is true.
Side effectsNone. The original input records are not changed.

student_report_print

student_report_print(inpt)

Prints the name and grade for every record in the supplied list.

ItemDescription
Parameterinpt: an iterable of dictionaries with Name and Grade keys.
Return valueNone. The function prints the report.
How it worksA for loop visits each dictionary. Dictionary indexing retrieves Name and Grade, and f-strings format each value.
Side effectsWrites the report heading, each student, and separators to standard output.

Limitations and Observations

Important source behavior

  • The file calls csv.DictReader but does not contain import csv. As written, execution raises NameError: name 'csv' is not defined before the functions are called.
  • avg_grade() divides by the global records list rather than by inpt. It works for the current call, but it makes the function depend on outside state.
  • If the CSV contains no data rows, the average calculation divides by zero.
  • The input, file reading, calculations, and printing happen at the top level. Importing the file would immediately prompt for a path and run the report.
  • The comment says grades should be higher than 80.0, but the implemented condition includes grades equal to 80.0.
  • Every row must contain the expected Name and Grade columns, and each grade must be convertible to a number.
