Mandelbrot Set Visualization

This script generates a visual approximation of the Mandelbrot set using Python, NumPy, and Matplotlib. It creates a grid of complex numbers, checks whether they stay bounded under a repeated mathematical transformation, and then displays the result as a 2D image.

Overview

The program uses the Mandelbrot iteration formula:

z = z^2 + c

where c is a complex number representing a point in the plane. Points that remain bounded after many iterations are considered part of the Mandelbrot set, while others diverge and are treated as outside the set.

Imported Libraries

  • numpy as np: used for numerical calculations and array operations.
  • matplotlib.pyplot as plt: used for plotting the final image.
  • matplotlib.patches as patches: imported but not actually used in this script.

Function 1: mandelbroth(n, x, y)

This function computes the Mandelbrot sequence for one complex number c = x + yi.

What it does

  • Creates the complex constant c from the given real and imaginary values.
  • Initializes an array with a single value 0.
  • Repeats the process n times:
    • it appends the next value in the sequence
    • each new value is computed as previous_value^2 + c
  • Returns the final generated array.

In simpler terms, it simulates the iterative process of the Mandelbrot formula for a single point.

Function 2: draw_mandelbroth(x, y)

This function builds a 2D image of the Mandelbrot set in an x by y grid.

What it does

  • Creates an array of size x * y filled with ones and reshapes it into a matrix.
  • Loops across a set of complex numbers within the region from roughly -1.5 to 0.5 on the real axis and -1 to 1 on the imaginary axis.
  • For each point, it calculates the Mandelbrot sequence and checks whether the value at index 100 has magnitude less than 2.
  • If the output remains bounded, the corresponding pixel is set to 0; otherwise it remains 1.
  • Finally, it calls plt.imshow(a) to display the generated image.

The condition:

if abs(mandelbroth(101, n1, n2)[100]) < 2:

is a common test used to estimate whether a complex number belongs to the Mandelbrot set after many iterations. If the value stays within a radius of 2, the point is considered part of the set.

How the image is created

The script calls:

draw_mandelbroth(200, 200)

This creates a 200 x 200 plot of points in the complex plane. Each pixel represents a single complex number. The script then colors the grid based on whether that sample is inside or outside the Mandelbrot set.

Note: The function name is spelled mandelbroth instead of the more common Mandelbrot. It is still the same concept and the script works as intended for this demonstration.

Result

When the script is run, it generates a visual representation of the Mandelbrot set in a Matplotlib window. The resulting pattern is a famous fractal shape with a highly detailed boundary.
